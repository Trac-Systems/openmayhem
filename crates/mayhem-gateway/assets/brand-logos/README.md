# Dashboard model provider logos

These local files mirror the provider artwork used by `C:\\Code\\OpenMayhem_Landing`.
Avatar and symbol files are copied byte-for-byte from its `public/brand-logos`
directory. Vector-provider SVGs are materialized from the same pinned
`simple-icons` paths used by `src/components/provider-logo.tsx` so the gateway
can serve every logo from an actual repository asset, including Qwen.
