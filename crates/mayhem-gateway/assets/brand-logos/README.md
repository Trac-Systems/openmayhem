# Dashboard model provider logos

These local files mirror the provider artwork used by `C:\\Code\\OpenMayhem_Landing`.
Avatar and symbol files are copied byte-for-byte from its `public/brand-logos`
directory. Vector-provider SVGs are materialized from the same pinned
`simple-icons` paths used by `src/components/provider-logo.tsx` so the gateway
can serve every logo from an actual repository asset, including Qwen.

The marks remain the property of their respective owners. Their appearance in
the model picker does not imply partnership or endorsement.

## Payment method marks

- `ethereum.svg` is the official transparent-background ETH diamond asset from:
  <https://ethereum.org/assets>
- `tnk-white.avif` is the white Trac T symbol supplied for the dashboard.

The card option uses a neutral card symbol so the dashboard does not imply that
only particular card networks are supported. The branded marks identify funding
methods only; their appearance does not imply partnership or endorsement.
